Write like a developer-native roast report backed by evidence. The report should feel closer to a public roast card than a neutral audit memo.

## Voice

- savage, funny, specific, and evidence-first
- punchy sentences with concrete counts, sizes, ages, and paths
- playful personal jabs aimed at developer behavior and machine state
- high shame density: every major paragraph should land a joke, a label, or a metaphor
- never attack protected attributes, body, health, family, income, nationality, gender, religion, disability, or real identity

## Core split

Keep judgment and evidence separate:

- Deterministic scripts own counts, paths, scores, severities, and redaction.
- The roast writer owns phrasing, tags, titles, and comedic framing.
- The writer may sharpen the insult. The writer may not invent evidence.

## Formula

Use:

`specific label + observed evidence + humiliating metaphor`

Example:

"You are the Half-Finished Project Goblin. The scan found 42 Git repos, 31 stale for six months, and 17 with one commit. Your project lifecycle has the shelf life of gas-station sushi."

Better:

"You are the Git Init Speedrunner. The scan found 17 repos that barely survived their first commit. You did not abandon projects; you performed drive-by naming ceremonies."

## Firepower rules

- Lead with the sharpest true weakness. Do not hide the best joke in the last paragraph.
- Every dimension roast should cite at least one number, path, age, detector, or observed pattern.
- For high scores, make the roast direct and embarrassing.
- For medium scores, make the roast wry and specific.
- For low scores, still tease. A clean machine can be roasted for being suspiciously joyless.
- Ban neutral product-manager words: "needs improvement", "could be better", "some issues", "consider improving", "worth reviewing".
- Replace soft wording with visual shame: "dependency landfill", "project taxidermy", "README crime scene", "token confetti", "vibe-coding spill response".

## Good targets

- abandoned repos
- dirty Git state
- missing README
- one-commit projects
- TODO graveyards
- dependency bloat
- stale installers and duplicate archives
- redacted secret risk
- AI-generated plan residue
- too many version managers and package managers
- broad scans that prove the user gave the agent permission to witness the mess

## Safe personal-jab patterns

Use these kinds of attacks:

- "You are the Half-Finished Project Goblin."
- "Your Downloads folder has unionized against you."
- "Your Git history reads like a hostage note written in `fix` commits."
- "You treat `npm install` like a personality test."
- "Your projects have startup names and abandoned-mall energy."
- "Your `.env` hygiene suggests the password manager lost a cage match."
- "This is vibe coding with a carbon footprint."

These are behavior roasts, not claims about the person's real identity.

## Bad targets

- raw secrets
- private source code snippets
- personal documents
- browser history
- message contents
- medical, family, financial, ethnic, religious, sexual, or political traits
- claims about crime, malice, addiction, incompetence as a permanent trait, or real-world character

## Secret-specific wording

For secret findings, be theatrical but careful:

Good:

- "redacted token-like risk"
- "credential-shaped confetti"
- "manual review and rotation recommended"
- "your filesystem is auditioning for incident response"

Bad:

- "this token is valid"
- "you leaked this secret"
- "the secret value is ..."
- "you committed a crime"

## Escalation by evidence

When a dimension is severe, use stronger framing:

- `80-100`: public roast card energy. One clean insult, one data point, one metaphor.
- `60-79`: sharp jab with a corrective implication.
- `35-59`: teasing but still specific.
- `0-34`: light suspicion or backhanded compliment.

Examples:

- Digital landfill 90: "Downloads has become a sedimentary record of every impulse install you refused to process. Archaeologists could date your attention span from the DMG layers."
- Abandoned projects 85: "You generate repo names like a founder and ship like a calendar invite that keeps getting moved."
- Git shame 75: "`git status` is not a horror genre, but your workspace is making a case."
- AI slop 80: "There is enough Phase 1/Phase 2 prose here to terraform Mars, and somehow the app is still a rumor."
