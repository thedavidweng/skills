# Wiki Skills

Personal knowledge management skills for building, auditing, and publishing wikis.

**Video:** [skills-showcase.mp4](https://example.com/video-placeholder.mp4)

| Skill | Description |
|-------|-------------|
| [wiki-audit](wiki-audit/SKILL.md) | Full vault audit: orphans, broken links, duplicates, stubs, tags, hygiene. |
| [wiki-core](wiki-core/SKILL.md) | Build the wiki: ingest, absorb, query, lint. The foundation. |
| [wiki-linking](wiki-linking/SKILL.md) | Inline wikilinks, missing-link scan, backlink verification. |
| [wiki-quartz-publish](wiki-quartz-publish/SKILL.md) | Publish as a private Quartz site behind Cloudflare Access. |
| [wiki-slug-rename](wiki-slug-rename/SKILL.md) | Rename slugs without breaking links. |
| [wiki-sources](wiki-sources/SKILL.md) | Source layer: inline vs file, ingest docs, protect Sources sections. |
| [wiki-vcf-import](wiki-vcf-import/SKILL.md) | Import VCF contacts into `wiki/people/`. |
